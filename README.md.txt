Simple CLI Calculator (Python)

Overview

A command-line calculator built using Python that performs basic arithmetic operations with continuous calculation and history tracking.

Features

* Addition, Subtraction, Multiplication, Division
* Continuous calculations using previous result
* Input validation and error handling
* Division by zero handling
* Calculation history tracking

Technologies Used

* Python
* Functions
* Nested loops
* Exception handling (try-except)
* Lists (for history storage)

How to Run

bash
python main.py
